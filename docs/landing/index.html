امکان استفاده از شماره پیامکی‌ها و اعتبارسنجی

فیلد شمارهٔ تماس یک فیلد متنی ساده نیست: مقدار آن سمت سرور اعتبارسنجی می‌شود و زیرساخت اتصال به درگاه‌های پیامکی ایرانی از همین نسخه در تنظیمات آماده است.

  • انتخاب درگاه پیامکی: کاوه‌نگار، SMS.ir، ملی‌پیامک، قاصدک یا آدرس سفارشی
  • ذخیرهٔ امن کلید API و شمارهٔ فرستنده در تنظیمات پلاگین
  • گزینهٔ الزام کد یک‌بارمصرف برای تأیید شمارهٔ کاربر
  • اعتبارسنجی سمت سرور روی هر فیلد، مستقل از اعتبارسنجی مرورگر
تجربهٔ مدیریت

تولید، توسعه و مدیریت فرم به سادگی

از یکی از چهار تمپلیت آماده شروع کنید یا از صفر بسازید. فیلدها را بکشید و رها کنید، و ورودی‌ها را در یک صندوق ورودی مرتب با جستجو، فیلتر و یادداشت خصوصی مدیریت کنید.

  • فرم‌ساز درگ‌اند‌دراپ با ده نوع فیلد استاندارد
  • تمپلیت‌های آماده: تماس ساده، تماس کامل، خرید کالا، ثبت‌نام رویداد
  • لیست فرم‌ها با تعداد ورودی، بازدید و درصد تبدیل
  • صندوق ورودی با انتخاب دسته‌جمعی، خوانده/نخوانده و یادداشت مدیر روی هر رکورد
  • کد جاسازی همیشه در دسترس: شورت‌کد، بلوک، و کد PHP
  • ویجت اختصاصی المنتور و ویجت گزارش در پیشخوان وردپرس

سبک و بهینه برای سئو

هیچ فریم‌ورک جاوااسکریپتی، هیچ فایل مینیفای‌شدهٔ سنگین و هیچ درخواست اضافه‌ای در کار نیست. فایل‌های فرانت‌اند فقط روی صفحاتی بارگذاری می‌شوند که واقعاً یک فرم را نمایش می‌دهند.

  • بارگذاری شرطی CSS و JS، فقط در صفحهٔ حاوی فرم
  • امکان خاموش کردن کامل CSS پلاگین اگر پوسته خودش استایل می‌دهد
  • خروجی HTML معنایی و در دسترس، با پیام خطای مخصوص هر فیلد
  • چیدمان راست‌به‌چپ و چپ‌به‌راست با ویژگی‌های منطقی CSS
  • جدول‌های اختصاصی دیتابیس به‌جای شلوغ کردن جدول نوشته‌ها و متاها

هوک‌ها و فیلترهای عمومی

هر رویداد مهم یک اکشن دارد و رفتارهای کلیدی قابل فیلتر هستند. برای مثال می‌توانید بلافاصله پس از ثبت هر ورودی، منطق خودتان را اجرا کنید. 

add_action(
  'mpro_forms_entry_created',
  function ( $entry_id, $form_id ) {
    // your logic here
  },
  10,
  2
